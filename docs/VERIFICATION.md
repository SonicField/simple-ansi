# Verification report

Recorded: 2026-09-29

## Goal

Provide a standalone, dependency-free streaming CLI that removes terminal
control sequences without attempting to reconstruct terminal display state.

The normal suite contains 250 named parser assertions, 1,000 deterministic
generated streams, one 1 MiB stream, exhaustive valid Unicode scalar coverage,
8 injected I/O assertions, and 10 end-to-end CLI scenarios.

## CI definition

`.github/workflows/ci.yml` declares explicit jobs for:

- Ubuntu 24.04 x86-64 with GCC and Clang
- Ubuntu 24.04 ARM64 with GCC and Clang
- macOS 15 Intel with Apple Clang
- macOS 15 ARM64 with Apple Clang
- ASan plus UBSan on Ubuntu x86-64
- GCC static analysis and ShellCheck

Each build job checks `uname -m`, runs the full suite, and tests a staged
installation. Checkout is pinned to a full commit SHA, jobs have timeouts, and
superseded runs are cancelled.

## Remaining uncertainty

The GitHub Actions matrix has not run because this repository has not been
published. In particular, Clang, macOS, and x86-64 results remain unobserved.
The deterministic generated tests are broad but are not a proof over every
possible byte stream. The parser implements the contract documented here; it
does not claim to emulate every vendor-specific terminal behaviour.
